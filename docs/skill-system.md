# Skill System

Skills extend agent capabilities. They are grouped into categories:

- **On-Chain**
  - Chain Reader – access Solana blockchain state.
  - Wallet Monitor – observe wallet balances and transactions.
  - DEX Scanner – scan decentralized exchanges (Raydium, Jupiter).
  - Market Data – fetch price feeds.

- **Intelligence**
  - Web Search – query internet resources.
  - Social Scanner – monitor social feeds for sentiment.
  - MEV Analyzer – spot miner extractable value opportunities.

- **Automation**
  - Scheduler – run tasks on a cron schedule.
  - Alert System – trigger alerts based on conditions.
  - API Connector – call external REST APIs.

- **Analysis**
  - Code Interpreter – run JS/TS code in sandbox.
  - Portfolio Tracker – evaluate holdings.
  - Risk Analyzer – assess trade risk.

- **Knowledge**
  - Private Memory – store agent-specific notes locally.
  - Vector Search – semantic search over documents.
  - Document Database – upload and query files.
